# Introduction

JavaScript (JS) is a high-level, dynamically typed, garbage-collected programming language primarily used to make software interactive and dynamic.

- Javascript first developed in 90s.
- ECMA standardized the Javascript language.
- V8 engine developed by chrome optimized the execution of code in browser.
- Nodejs developed with the help of v8 to execute code in backend.
- JavaScript was initially created as a browser-only language, but it is now used in many other environments as well.
- Javascript is JIT compiled language.
